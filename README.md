# 보카 문제지

영단어만 입력하면 뜻 · 동의어 · 예문 · 어형 변화 문제를 자동으로 만들어 주는
스터디 그룹용 단어 시험 앱. 파일 하나로 돌아갑니다. 빌드도, 서버도, 설치도 없습니다.

## 두 가지 모드

이 앱은 어디에 올려놨느냐에 따라 두 가지로 동작합니다.

| | Claude 링크 (문제 만드는 곳) | GitHub Pages (시험 보는 곳) |
|---|---|---|
| 로그인 | 필요 | **불필요** |
| 단어 → 문제 자동 생성 | O | X |
| 챕터 공유 저장 | O | X (기기별 저장) |
| 시험 · 단어장 · 점수 | O | O |

문제는 **한 사람이 Claude 링크에서 만들고**, 시험은 **모두가 GitHub Pages에서** 봅니다.
자동 생성은 만든 사람의 Claude 계정으로 돌아가므로, 시험 보는 사람은 계정이 필요 없습니다.

## 챕터를 옮기는 방법

Claude 링크에서 챕터를 만든 뒤 **내보내기 → 코드 복사**. 그 코드를 옮기는 방법 세 가지:

1. **파일에 심기 (제일 편함)** — `index.html` 안의 `const BAKED = [];` 에 챕터 JSON을
   넣어 두면, 사이트를 여는 순간 챕터가 이미 들어 있습니다. 받는 사람은 할 일이 없습니다.
2. **링크에 붙이기** — 주소 뒤에 `#c=코드` 를 붙여서 보냅니다.
   예: `https://<username>.github.io/vocatest/#c=V1Z...`
   누르면 알아서 들어갑니다. 40단어 기준 코드가 약 4,000자라 카톡으로 보내도 됩니다.
3. **코드만 보내기** — 받는 사람이 **가져오기** 에 붙여넣습니다.

## 문제 유형

단어에 어떤 정보가 있느냐에 따라 자동으로 정해집니다.

- **영 → 한**, **한 → 영**, **스펠링** (직접 입력)
- **동의어** — 오답은 *다른 단어의* 동의어에서 가져오므로 헷갈립니다
- **빈칸** — 그 단어의 예문에서 단어를 지운 문제
- **어형 변화** — 같은 문장에 `work / works / working / worked` 중 맞는 형태 고르기

오답 선택지는 항상 **같은 챕터의 다른 단어**에서 나옵니다. 아무 단어나 넣는 것보다
훨씬 어렵고, 실제로 외웠는지 가려집니다.

## 그 밖에

- **틀린 것만 다시 풀기**, 챕터별 최고점 기록
- **뜻 가리기** — 단어장에서 한글 뜻을 흐리게 가렸다가 눌러서 확인 (빨간 시트지)
- 데스크톱에서 **1~4 숫자키**로 빠르게 풀기
- 점수와 오답 기록은 각자 기기에만 저장됩니다. 서로 볼 수 없습니다.

## 주의

- 뜻과 예문은 자동 생성이라 **해커스 보카 원문과 다를 수 있습니다.**
  저장 전 검토 화면에서 고칠 수 있으니 한 번 훑어보세요.
- GitHub Pages 무료 계정은 저장소가 **공개**입니다. 심어 둔 챕터도 공개로 보입니다.
